Mathematics of Backpropagation

1. Forward Propagation

Computes layer-by-layer activations from features to predictions:

Z^[l] = W^[l] · A^[l-1] + b^[l] A^[l] = ReLU(Z^[l]) = max(0, Z^[l]) A^[L] = Softmax(Z^[L])_i = exp(Z_i^[L]) / Σ exp(Z_j^[L])

2. Categorical Cross-Entropy Loss

Measures discrepancy between predicted probabilities and ground truth one-hot vector:

L(y, ŷ) = - Σ (y_k · ln(ŷ_k))

3. Backward Propagation (Chain Rule Derivatives)

Calculates exact analytical gradients propagated from output back to input:

δ^[L] = ∂L / ∂Z^[L] = ŷ - y (Output Layer Error) δ^[l] = ((W^[l+1])^T · δ^[l+1]) ⊙ ReLU'(Z^[l]) (Hidden Layers) ∂L / ∂W^[l] = δ^[l] · (A^[l-1])^T ∂L / ∂b^[l] = δ^[l]

4. Parameter Update (Adam Optimizer)

Applies exponential moving averages of gradients (m_t) and squared gradients (v_t):

W^[l] ← W^[l] - α · m̂_t / (sqrt(v̂_t) + ε)
